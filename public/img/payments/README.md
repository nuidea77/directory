# Зээлийн аппуудын лого

Файлын нэр нь `config/payments.php`-ийн `slug`-тай тааруулна:

```
lendmn.svg   storepay.svg   pocket.svg   sono.svg      ard.svg
toki.svg     hipay.svg      monpay.svg   qpay.svg      socialpay.svg
```

- `.svg` (эрхэм), `.png`, `.webp` дэмжинэ — эхэлж олдсоныг нь авна.
- Дөрвөлжин тэмдэг (icon) байвал хажууд нь аппын нэр бичигдэнэ.
- Лого нь өөрөө нэрээ агуулсан (wordmark) бол `config/payments.php` дотор
  тухайн аппад `'wordmark' => true` гэж нэмнэ — тэгвэл текст давхардахгүй.
- Файл байхгүй бол брэндийн өнгөтэй түр тэмдэг гарна, апп ажиллахад
  саад болохгүй.

Логог тухайн байгууллагын албан ёсны brand kit / press хуудас, эсвэл
худалдагчийн (merchant) гэрээгээр авсан материалаас нь тавина —
эдгээр нь тухайн компаниудын барааны тэмдэг тул зөвшөөрөгдсөн эх сурвалжаас
авах шаардлагатай.
